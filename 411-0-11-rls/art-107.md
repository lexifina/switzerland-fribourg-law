# Art. 107 Communication dans un cas d'espèce
1 Les directions d'établissement peuvent communiquer, dans un cas d'espèce, des données personnelles d'un ou d'une élève, sans le consentement des personnes concernées, si le ou la destinataire exerce une tâche publique qui sert l'intérêt de l'enfant et que les données communiquées lui soient absolument nécessaires pour l'accomplissement de sa fonction.
2 Sont réservés les obligations particulières de garder le secret (art. 42 LS) ainsi que les principes régissant le traitement de données personnelles selon la législation y relative.
