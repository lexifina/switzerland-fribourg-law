# Art. 55 Candidatures multipliées
1 Pour les élections se déroulant selon le mode de scrutin proportionnel, si une personne est portée candidate sur plus d'une liste, son nom est immédiatement éliminé de toutes les listes.
2 Pour l'élection au Grand Conseil, si les listes sont déposées dans le même cercle, le nom est éliminé par le préfet; si elles le sont dans des cercles différents, le nom est éliminé par la Chancellerie d'Etat.
3 Pour les élections communales, le nom est éliminé par le secrétariat communal.
