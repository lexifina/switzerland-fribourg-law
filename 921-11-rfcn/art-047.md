# Art. 47 Plan forestier régional – Contenu (art. 48 LFCN)
1 Le plan forestier régional contient notamment les documents suivants:
a) les documents de base ou leurs références pour la région concernée;
b) les fiches de mesures;
c) les fiches de coordination.
2 Le Conseil d'Etat indique, dans le plan forestier régional, les documents liant les autorités.
