# Art. 134 Règles sur les distances – Règles particulières sur les distances
1 Les prescriptions sur les distances de la législation spéciale sont réservées.
2 Les distances minimales à respecter entre les constructions et les installations de transport existantes ou prévues, les eaux publiques, les forêts, les limites de fonds et les points de vue peuvent également être réglées dans un plan d'affectation des zones ou un plan d'aménagement de détail au moyen d'alignements. Les alignements ont la priorité sur toutes les autres prescriptions sur les distances. Les alignements obligatoires prescrivent l'édification des constructions sur l'alignement.
